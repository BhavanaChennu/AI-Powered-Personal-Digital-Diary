# AI-Powered Personal Digital Diary

Full-stack Java + React app with Groq AI integration.

## Structure
- `diary-backend/` → Spring Boot REST API
- `diary-frontend/diary-frontend/` → React Web App

## Tech Stack
- Backend: Spring Boot, Java 17, MySQL, JWT, Spring Security
- Frontend: React.js
- AI: Groq API

## Setup
1. Create MySQL database: `diary_db`
2. Copy `diary-backend/application.properties.example` to `application.properties`
3. Fill in your credentials
4. Run backend in Eclipse
5. Run frontend: `npm start`
